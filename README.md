# ALYASSER عباءات

متجر إلكتروني لعباءات ALYASSER (فاشن). موقع متجاوب يتضمن:
- صفحات أقسام (عبايات، فساتين، نقاب، تشكيلات، تخفيضات...)
- صفحات منتجات بصور ومقاسات تفصيلية
- سلة تسوق ومفضلة وإتمام طلب
- دعم كامل للعربية (RTL) والإنجليزية (LTR) مع تبديل فوري

## تقنية
- HTML + CSS (Bootstrap) + JavaScript
- صور وملفات وسائط داخل `assets/img`

## تشغيل محلي
افتح `index.html` في المتصفح، أو استخدم أي خادم محلي (مثل Live Server).

جميع الحقوق محفوظة لـ ALYASSER.
